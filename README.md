# Telecom Customer Churn Prediction Using Machine Learning

## Project Overview

This university group project focuses on predicting customer churn in the telecommunications industry using machine learning classification techniques.

The project involves data preprocessing, exploratory data analysis, feature engineering, model training, evaluation and comparison.

## My Individual Contributions

I was responsible for:

- **Data Preprocessing:** Preparing and cleaning customer data for machine learning.
- **Exploratory Data Analysis:** Analysing customer characteristics and churn patterns.
- **Feature Engineering:** Creating and transforming features to improve the modelling process.
- **Random Forest Evaluation:** Evaluating the Random Forest classifier and reviewing its predictive performance.
- **Model Comparison:** Collaborating with team members to compare four machine learning models and select the most suitable approach.

## Machine Learning Models Compared

1. Logistic Regression
2. Random Forest
3. Gradient Boosting
4. Support Vector Machine (SVM)

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Evaluation

The project used classification metrics, including accuracy, precision, recall and F1-score, to assess model performance.

The final notebook recommends a balanced Logistic Regression approach, considering the importance of identifying customers at risk of churn.
